# Local speech model

Download and unzip [vosk-model-en-us-0.22-lgraph.zip](https://alphacephei.com/vosk/models/vosk-model-en-us-0.22-lgraph.zip) into this directory. The app expects the model at `models/vosk-model-en-us-0.22-lgraph/` when run from the project root.

The downloaded model is too large to track in Git. See the [root README's voice input instructions](../README.md#voice-input-practice-tab) for more details.
