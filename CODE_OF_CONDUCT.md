# Code of Conduct

## Our Pledge

As members of the AI Coding Interview Prep project, we pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards

We expect everyone to:

- be respectful and considerate in all project spaces
- use welcoming language
- accept constructive feedback gracefully
- respect differing viewpoints and experiences
- work to resolve disagreements peacefully

## Reporting

If you experience or witness unacceptable behavior, please report it to the project maintainers by opening an issue or contacting the team directly.

## Scope

This Code of Conduct applies to all project spaces, including the repository, issue tracker, pull requests, GitHub wiki, and any project-related communication channels.
